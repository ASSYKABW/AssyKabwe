# CareerBoost - AI-Powered Job Success Platform

A modern, responsive marketing website for CareerBoost, featuring AI-powered career acceleration tools for job seekers and intelligent recruiting solutions for HR professionals.

## 🚀 Features

### For Job Seekers
- **AI Career Coach** - Personalized career guidance
- **Resume Optimization** - ATS-compatible resume enhancement
- **Interview Preparation** - Mock interviews with AI feedback
- **Job Matching** - Intelligent job recommendations
- **Career Analytics** - Progress tracking and insights
- **Skill Development** - Personalized learning paths

### For Recruiters
- **AI Candidate Matching** - Smart talent sourcing
- **Automated Screening** - Resume analysis and ranking
- **Interview Scheduling** - Automated calendar management
- **Team Collaboration** - Hiring pipeline management
- **Advanced Analytics** - Recruitment performance insights

## 🚀 Getting Started

1. **Open the website**: Simply open `index.html` in your web browser
2. **Local development**: Use a local server for best experience:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```
3. **Navigate**: Use the top navigation to explore different pages
