# CareerBoost - AI-Powered Job Success Platform

A modern, responsive marketing website for CareerBoost, an AI-powered career acceleration platform designed for both job seekers and recruiters.

## 🚀 Features

### Core Product Features
1. **AI Resume Builder** - ATS-optimized resumes with real-time feedback
2. **Smart Job Matching** - Personalized job recommendations using AI
3. **Interview Prep AI** - Mock interviews with AI-powered feedback
4. **Career Path Analytics** - Data-driven career progression insights
5. **Networking Intelligence** - AI-suggested networking opportunities

### Website Features
- **Dual User Experience** - Separate flows for Job Seekers and Recruiters
- **Responsive Design** - Mobile-first approach with seamless desktop experience
- **Modern UI/UX** - Clean, trust-driven design with conversion optimization
- **Interactive Elements** - Dynamic pricing toggle, user type selector, modals
- **Performance Optimized** - Fast loading, lazy loading, and PWA-ready
- **Accessibility** - WCAG compliant with keyboard navigation support

## 🛠 Technical Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Variables and Grid/Flexbox
- **Icons**: Font Awesome 6
- **Fonts**: Inter (Google Fonts)
- **Images**: Unsplash for placeholder images
- **Performance**: Intersection Observer API, Lazy Loading
- **PWA Ready**: Service Worker registration included

## 🎨 Customization Guide

### Brand Colors
Update CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;    /* Main brand color */
    --primary-dark: #4f46e5;     /* Darker variant */
    --primary-light: #8b5cf6;    /* Lighter variant */
    --secondary-color: #10b981;   /* Success/accent color */
}
```

### Content Updates
- **Company Info**: Update brand name, tagline, and descriptions
- **Features**: Modify the five core features in the features section
- **Pricing**: Adjust pricing tiers and features
- **Testimonials**: Replace with real customer testimonials
- **Contact Info**: Update footer links and contact information

### Images and Assets
- Replace placeholder images with actual product screenshots
- Add company logo in the navigation
- Update favicon and app icons
- Add product demo videos or animations
